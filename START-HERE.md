## ⚡ Quick Start (5 passos)

```bash
# 1. Preparar
cp -r bncc-platform ~/meu-projeto
cd ~/meu-projeto
npm install

# 2. Supabase
# Criar projeto em supabase.com
# Executar supabase-schema.sql no SQL Editor
# Copiar credenciais

# 3. Variáveis
cp .env.example .env.local
# Editar .env.local com suas credenciais

# 4. Seed
npm run seed

# 5. Rodar!
npm run dev
# http://localhost:3000
```
